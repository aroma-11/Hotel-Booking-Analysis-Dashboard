# 🏨 Hotel Booking Analysis Dashboard

## 📌 Project Overview
The Hotel Booking Analysis Dashboard is a data analytics project developed using Microsoft Excel. The main objective is to analyze hotel booking data, identify booking patterns, understand customer behavior, and study cancellation trends.

This project provides insights into hotel performance, guest categories, monthly bookings, and room status to support better business decisions.

## 🎯 Project Objectives
- Analyze hotel booking and cancellation trends.
- Compare City Hotel and Resort Hotel bookings.
- Understand guest categories such as Couples, Families, and Singles.
- Analyze monthly guest and cancellation trends.
- Study desired and undesired room assignments.
- Generate meaningful business insights from hotel booking data.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Pivot Tables
- Data Analysis
- Data Visualization
- Data Cleaning

## 📂 Dataset Information
The dataset contains hotel booking information with columns such as:

- Hotel Type
- Booking Cancellation Status
- Arrival Year
- Arrival Month
- Number of Adults
- Number of Children
- Country
- Reserved Room Type
- Assigned Room Type
- Reservation Status
- Room Status
- Guest Type

## 📊 Key Analysis Performed
1. **Hotel Performance Analysis:** Comparison of bookings between City Hotel and Resort Hotel.
2. **Guest Type Analysis:** Analysis of Couples, Families, and Singles.
3. **Monthly Booking Analysis:** Understanding monthly guest trends.
4. **Cancellation Analysis:** Identifying booking cancellation patterns.
5. **Room Status Analysis:** Comparing desired and undesired room assignments.

## 💡 Key Insights
- City Hotel has a higher booking volume than Resort Hotel in the prepared pivot analysis.
- Couples represent the largest guest category.
- Monthly guest numbers vary throughout the year.
- Booking cancellations differ across hotel types and guest categories.
- Desired room assignments are significantly more common than undesired assignments.
